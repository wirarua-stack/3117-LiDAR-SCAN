# Reference application analysis

This project is an independent implementation. No source, assets, private APIs, or interface design from Polycam or KIRI Engine are used.

| Capability | Polycam / KIRI Engine public-product comparison | 3117 MVP |
|---|---|---|
| LiDAR scan | Publicly marketed by both products; exact behaviour/version varies | Real ARKit mesh capture |
| Photogrammetry | Publicly marketed workflow | Deferred (Phase 2) |
| Point cloud / mesh export | Public-product capability; output availability varies by plan/version | Mesh archive + OBJ foundation |
| BIM / Revit | Workflow integration varies and needs per-version verification | Human-reviewed scan-to-BIM roadmap |

Before product decisions, record the observed app version, platform, plan, date, screenshots made with permission, and the vendor's current documentation. This document intentionally makes no assertion about undocumented functionality.
